# تغذية / الدكتورة جهاد حسن

تطبيق ويب يعمل بدون إنترنت ويُثبَّت على الهاتف كتطبيق (PWA).

## الملفات
- `index.html` — التطبيق كاملاً (المكتبات والخطوط داخله)
- `manifest.webmanifest` — اسم التطبيق وأيقونته وألوانه عند التثبيت
- `sw.js` — يحفظ التطبيق في الجهاز ليعمل بدون إنترنت
- `icons/` — أيقونات التطبيق
- `.nojekyll` — يمنع GitHub من معالجة الملفات

## الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً على github.com (مثلاً باسم `taghthia`).
2. ارفع كل الملفات بنفس ترتيبها، ومعها مجلد `icons`.
3. من المستودع: Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** و **/ (root)** ← Save.
4. بعد دقيقة أو دقيقتين يصبح الرابط: `https://اسم-المستخدم.github.io/taghthia/`

## التثبيت على الهاتف
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← «تثبيت التطبيق»، أو من الإعدادات داخل التطبيق ← «تثبيت التطبيق».
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

افتح التطبيق مرة واحدة وأنت متصل بالإنترنت، وبعدها يعمل بدون إنترنت.

## البيانات
بيانات الأشخاص والأطباق محفوظة في الهاتف فقط، ولا تُرفع إلى GitHub ولا يراها أحد.
صدّر نسخة احتياطية بشكل دوري من الإعدادات ← «تصدير الكل».

## نشر تحديث لاحقاً
1. استبدل `index.html` بالنسخة الجديدة.
2. في `sw.js` غيّر السطر `const VERSION = "taghthia-v4";` إلى رقم جديد مثل `taghthia-v5`.
3. ارفع الملفين. يصل التحديث للهاتف عند فتح التطبيق وهو متصل بالإنترنت.

## كلمة المرور
- يطلب التطبيق كلمة المرور أول مرة فقط على كل جهاز، ثم يتذكر الدخول. الافتراضية: `Jahoodi` (الحروف الكبيرة والصغيرة مهمة).
- لتغييرها: الإعدادات ← «كلمة المرور». وفيها زر «قفل الآن» ليطلبها عند الفتح القادم.
- كلمة المرور خاصة بكل جهاز، ولا تدخل في ملف النسخة الاحتياطية.
- إذا نُسيت: «نسيت كلمة المرور؟» يمسح بيانات التطبيق في الجهاز وتعود الافتراضية، ثم تستورد نسختك الاحتياطية.
